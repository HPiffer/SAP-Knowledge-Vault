# Glossário SAP

| Termo | Significado | Observação |
|---|---|---|
| ABAP | Advanced Business Application Programming | Linguagem e plataforma de desenvolvimento SAP |
| ADT | ABAP Development Tools | Ferramentas ABAP baseadas em Eclipse |
| BAdI | Business Add-In | Ponto de extensão orientado a objetos |
| BAPI | Business Application Programming Interface | Interface de negócio liberada para consumo |
| BTP | Business Technology Platform | Plataforma de serviços, extensão, integração e dados |
| CDS | Core Data Services | Modelagem semântica de dados |
| DCL | Data Control Language | Controle de autorização aplicado a entidades CDS |
| EML | Entity Manipulation Language | Acesso tipado a business objects RAP em ABAP |
| OData | Open Data Protocol | Protocolo usado na exposição de serviços |
| RAP | ABAP RESTful Application Programming Model | Modelo de desenvolvimento de serviços e aplicações ABAP |
| RFC | Remote Function Call | Comunicação remota entre sistemas |
| UI5 | SAPUI5 | Framework de interface web da SAP |

Adicione termos quando forem usados em uma nota. Prefira definições curtas e ligue a uma nota de estudo para explicações extensas.
