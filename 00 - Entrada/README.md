# Entrada de novos conteúdos

Deposite aqui todo material novo antes de incorporá-lo à base: notas, código, imagens, PDFs, planilhas, apresentações ou pacotes.

Depois, abra o Codex na raiz do repositório e peça:

> Processar a Entrada

## Regras

- Não faça commit dos arquivos brutos desta pasta.
- Não coloque aqui senhas, tokens, chaves privadas, dados pessoais ou conteúdo confidencial de clientes.
- Não renomeie nem apague os arquivos enquanto uma triagem estiver em andamento.
- Itens que exigirem decisão humana aparecerão localmente em `_Revisar`.

O conteúdo desta pasta, exceto este README, é ignorado pelo Git.
