# SAP - Referência de tipos de desenvolvimento

## Uso rápido

Mapa inicial para decidir onde registrar um artefato técnico nesta base. Não substitui a documentação do produto nem uma decisão de arquitetura.

## Tabela de consulta

| Necessidade | Área da base | Registro mínimo |
|---|---|---|
| Modelo de dados semântico | CDS | Fonte, associações, autorização e release |
| Serviço ou business object ABAP | RAP | Tipo de implementação, contrato, testes e exposição |
| Interface web | Fiori e UI5 | Aplicação, serviço, navegação e segurança |
| Comunicação entre sistemas | Integrações | Contrato, autenticação, observabilidade e reprocessamento |
| Lógica reutilizável | ABAP | Interface, efeitos colaterais, testes e performance |
| Automação de qualidade | Qualidade e Testes | Escopo, entrada, resultado esperado e evidência |

## Limitações

Uma solução pode envolver mais de uma tecnologia. Guarde a nota pelo propósito predominante e represente as demais tecnologias no frontmatter.
