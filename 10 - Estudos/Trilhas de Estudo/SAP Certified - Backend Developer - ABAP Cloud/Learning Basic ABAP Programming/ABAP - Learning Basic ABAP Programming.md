# ABAP - Learning Basic ABAP Programming
Sobre este curso

Após concluir este curso, você será capaz de:

- Trabalhar com o ambiente de desenvolvimento ABAP
- Aplicar técnicas básicas de ABAP
- Criar programas orientados a objetos simples
- Usar ABAP SQL para acessar o banco de dados
- Trabalhar com Business Objects e a Entity Manipulation Language
- Desenvolver aplicações simples com o ABAP RESTful Application Programming Model
