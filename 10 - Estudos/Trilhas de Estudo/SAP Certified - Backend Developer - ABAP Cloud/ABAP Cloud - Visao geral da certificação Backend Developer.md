# ABAP Cloud - Visao geral da certificação Backend Developer

## Sobre a certificacao

**SAP Certified - Backend Developer - ABAP Cloud**

## Visao geral

Esta certificacao verifica que voce conhece os principios centrais da linguagem de programacao ABAP e e capaz de desenvolver aplicacoes robustas usando o **ABAP RESTful Application Programming Model (RAP)**. Alem disso, valida sua proficiencia em utilizar o **Joule para desenvolvedores** — o assistente de IA generativa da SAP — para acelerar o ciclo de vida de desenvolvimento por meio de geracao, explicacao e otimizacao de codigo. Esta certificacao comprova que voce possui o conhecimento abrangente e as habilidades praticas necessarias para contribuir de forma efetiva em equipes de projeto em um papel mentorado (*mentored role*), utilizando fluxos de trabalho de desenvolvimento modernos e assistidos por IA. Esta e uma versao beta do exame pratico.
